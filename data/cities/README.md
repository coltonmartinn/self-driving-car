# Bundled cities

Ready-to-drive worlds for the live demo and the trainer, built by
`scripts/bundle-cities.js` from OpenStreetMap data around each place
(500 m radius).

Map data © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors,
available under the [Open Database License (ODbL)](https://opendatacommons.org/licenses/odbl/).
These files are derived from that data and are shared under the same license.
